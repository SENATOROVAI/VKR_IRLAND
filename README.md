## Краткое описание задачи

Автоматизация подсчёта и классификации сельскохозяйственных животных (крупный рогатый скот / овцы) по аэрофотоснимкам с использованием методов компьютерного зрения.

**Три исследовательских вопроса:**

| # | Вопрос |
|---|--------|
| RQ1 | Может ли кастомная CNN достичь точности предобученных ImageNet-моделей? |
| RQ2 | Насколько модели устойчивы к изменениям освещённости и степени перекрытия объектов? |
| RQ3 | Обеспечивает ли одноэтапный детектор (YOLOv8) точный подсчёт животных? |

## Выводы

### Проверка гипотез

**H1 — предобученные модели превосходят кастомную CNN:**  
*Частично подтверждена.* Только VGG-16 значимо превзошла кастомную CNN (McNemar p < 0.05). ResNet-50 и MobileNetV2 оказались хуже или не отличались статистически. Кастомная CNN заняла 2-е место из 4 — неожиданно сильный результат для модели без предобучения.

**H2 — аугментация улучшает обобщающую способность:**  
*Подтверждена.* Аугментация добавила +0.62 п.п. точности на тестовой выборке.

**H3 — YOLOv8 лучше наивных базовых линий в подсчёте:**  
*Подтверждена.* YOLOv8 MAE = 1.58 против 11.96 у наивного предсказателя (медиана) — улучшение в 7.6×.

### Устойчивость к условиям съёмки

- Наихудшая точность классификации по освещённости: **0.918** (dim-свет)
- Наихудшая точность по степени перекрытия: **0.931** (высокое occlusion)
- VGG-16 показал наилучшую робастность во всех подгруппах
